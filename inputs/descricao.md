# Criação de um chatbot que utiliza como base de dados arquivos e pdf do próprio usuário.

<img width="1327" height="732" alt="image" src="https://github.com/user-attachments/assets/b3a74be8-b1a0-4de0-8a79-c2dc59283f2e" />

Conforme descrito nas orientações foi criado um chatbot que efetua pesquisas em pdfs carregados pelo usuário; no caso em tela foram usados 8 arquivos
que versam sobre a produção de ovos no Brasil. Os arquivos são de fontes variadas como estudos, artigos, material jornalístico etc.

Foram feitos todos os procedimentos até o final sem, no entanto crir a aplicação como um Web Chat.
